# Class reference

palmy styles with Tailwind class strings, parsed at runtime by `apply_classes` and `apply_token` in `palmy/class.odin`. This page is generated from that parser, so it lists exactly what it accepts. The [Classes](/docs/classes) guide explains how styling works; this is the list.

Two things to know before reading the tables:

- **A class palmy does not understand is dropped silently.** Check the tables below rather than assuming a Tailwind utility works.
- **Accepted is not the same as supported.** Some utilities parse and do nothing, so that class strings copied from a web project need no cleaning. They are listed at the end.
