# A tour of the map, at 1500x940.
#
# Two things shape this script.
#
# Almost everything is driven by the pointer. palmy on a headless compositor
# currently receives only the first `wtype` invocation — the seat advertises
# and withdraws its keyboard capability around each one and the client does not
# re-bind — so the script spends its one reliable burst of keystrokes on the
# search query and does the rest with clicks. The zoom buttons, the fly-to
# animation from a search result and the route tool between them cover panning,
# zooming, searching, routing and markers without needing a second one.
#
# And the pointer keeps moving between actions rather than the script simply
# waiting. An idle palmy window blocks in poll and commits no frames, so a
# `wait 2` with nothing happening records as nothing at all — the capture ends
# at the last commit. Moving the pointer over the map updates the coordinate
# read-out, which asks for a frame, so the recording stays continuous.

wait 1.2
move 900 400
wait 0.3

wait 0.3
