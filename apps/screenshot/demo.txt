# Screenshot demo.
#
# grim and slurp against the real screen, with the result decoded by palmy and
# shown in the window.
#
# What this script does to the machine: it takes three captures into /tmp, it
# copies one of them into ~/Pictures under a dated name that cannot collide
# with a file already there, and it puts one on the clipboard. The /tmp
# originals are removed when the window closes; nothing is ever deleted or
# replaced.

wait 2.0
# A whole-screen capture. This window is part of the screen, so it appears in
# its own shot — which is what the delay exists for.
key Return
wait 4.5

# Save it into ~/Pictures. The name is dated, and if that name is taken the
# tool picks the next one rather than overwriting anything.
key s
wait 3.0

# Copy it to the clipboard as image/png, through wl-copy.
key c
wait 3.0

# Zoom in. Past two times magnification palmy switches from bilinear to
# nearest, so a zoomed screenshot shows real pixels rather than mush.
key equal
wait 2.0
key equal
wait 2.5
key equal
wait 3.0
key f
wait 2.0

# The delay, for getting this window out of the way first. T cycles it.
key t
wait 1.5
key Return
wait 5.0

# Another one, so the list has more than one capture in it. The delay is put
# back to none first — one T per frame, so each press needs its own beat or the
# recorder's keystrokes land in the same frame and only one of them counts.
key t
wait 0.5
key t
wait 0.5
key t
wait 1.0
key Return
wait 4.0

# Move through the session's captures. Each one is decoded on selection.
key Down
wait 2.5
key Up
wait 2.5

# Every command this tool has run.
key g
wait 4.5
key Escape
wait 1.2

# Every key, including A — which re-captures the last region with no overlay
# and no drag, once there has been one.
key question
wait 4.5
key Escape
wait 1.5

# Region mode. slurp takes the screen and waits for a rectangle; this
# compositor build has no click dispatcher, so there is no way to synthesise
# the drag — Escape gives the screen back and the capture is simply cancelled,
# which is the path worth showing here anyway.
key 3
wait 2.0
key Return
wait 3.0
key Escape
wait 3.0
