# Sheets — multiple sheets, frozen panes and charts.
#
# This is the same story as apps/sheets/film.txt, in the recorder's grammar.
# It is not what built demo.mp4: palmy's Wayland keyboard currently delivers
# one key event per window and then goes silent, so a recorded take shows a
# single keystroke and a still picture. `bash apps/sheets/film.sh` drives the
# same key handler through palmy's offscreen path instead. Use this file with
# apps/tools/headless-record.sh once the keyboard works again.
wait 1.4

# The header row and the label column are frozen: scroll and they stay put.
key Page_Down
wait 0.7
key Page_Down
wait 0.9
chord ctrl+Home
wait 1.0

# The Summary tab is nothing but cross-sheet references, plus a chart of them.
chord ctrl+Next
wait 1.4
key Down
wait 0.5
key Down
wait 0.5
key Down
wait 0.9
chord ctrl+Home
wait 0.6

# Change one number on Sales...
chord ctrl+Prior
wait 0.9
chord ctrl+g
wait 0.5
type B5
key Return
wait 0.7
type 500
key Return
wait 1.2

# ...and the Summary totals and the chart have already followed it.
chord ctrl+Next
wait 1.8

# A third sheet, reading from both of the others.
chord alt+s
wait 0.9
chord alt+n
wait 0.5
type Check
key Return
wait 0.9
type Revenue total
key Return
type =SUM(Sales!D3:D7)
key Return
wait 0.8
type Matches summary
key Return
type =Summary!B8=A2
key Return
wait 1.4

# Freeze this sheet at the cursor too.
chord ctrl+Home
wait 0.4
key Down
key Right
wait 0.4
chord alt+f
wait 1.4

# And a pie chart of the summary, drawn into the grid.
chord ctrl+Prior
wait 0.8
chord ctrl+g
wait 0.5
type A2:B6
key Return
wait 0.7
chord alt+p
wait 2.4
