# Docs — tables, pictures, and find with case and whole-word.
#
# ## Why every key is a `chord capslock+…`
#
# `headless-record.sh` runs one `wtype` per step, and each invocation attaches
# a fresh virtual keyboard and starts sending before the compositor has
# finished handing focus to it — so an invocation's **first** key event is
# occasionally dropped. A bare `key Return` is a one-event invocation, so a
# drop loses the whole step; in a take of this script with bare keys, four of
# five Returns went missing and the document came out as one run-on paragraph.
#
# A chord is a multi-event invocation: the modifier press goes first and is
# the one that gets sacrificed. Caps Lock is the modifier to use, because it
# is the one palmy reports that this app's key table deliberately ignores —
# `plain` and `edit_count` mask on Shift/Ctrl/Alt/Super only — so the key
# fires identically whether or not the Caps Lock press arrived, and typing
# after it is unaffected. Every bare key below is wrapped for that reason and
# no other; a person pressing Return gets the same result.
