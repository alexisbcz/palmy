# Translations, locale and time zone in the session stack — notes

Owner: apps/kit/i18n.odin (+ apps/kit/i18n_test/), apps/greeter/,
distro/login/, distro/init/, distro/base/, distro/locale/*/greeter.msg,
distro/locale/README.md, this file.

## What exists

- **`apps/kit/i18n.odin`**, the API of INSTALLER.md: `i18n_init(domain,
  lang="")`, `tr`, `trf`, `trn`, `i18n_set_language`, `i18n_is_rtl`, plus
  `trnf` (trn then format), `i18n_language()` (the catalogue in use, "en" for
  none), `i18n_shutdown`, `lang_is_rtl(name)`, `i18n_candidates`,
  `i18n_env_languages`, and `i18n_parse` / `i18n_load_file` / `i18n_lookup` /
  `i18n_catalog_destroy` for code that wants one catalogue in hand (a language
  list showing each language's `name =`).
  - Root `/usr/share/palm/locale`, `PALM_LOCALE_DIR` overrides it.
  - Environment order: `LANGUAGE` (colon list), then the first of `LC_ALL`,
    `LC_MESSAGES`, `LANG`. Each name expands most → least specific
    (`fr_FR.UTF-8@euro` … `fr_FR`, `fr`), and *every* catalogue found is
    chained, so a lookup falls fr_FR → fr → msgid. `C`/`POSIX` stop the
    search (English).
  - Plural rule: the header's `plural =` is a full gettext C expression,
    evaluated by a small recursive-descent parser — Arabic's real six-form
    rule is used rather than simplified to `n != 1`. A rule that does not
    parse falls back to `n != 1` with one stderr line.
  - RTL: `direction = rtl|ltr` in the header wins; otherwise ar, he, fa, ur
    (and yi, ps, sd, ug, dv, ckb). False when no catalogue matched, since
    English is then on screen.
  - `trf`/`trnf` format into the temp allocator (palmy clears it per frame).
    `tr` returns catalogue-owned strings, valid until the language changes.
  - Global state, not locked: init and switch on the UI thread.
- **Format** for translators: `distro/locale/README.md` (header keys
  `plural`, `language`, `name`, `english`, `direction`; Odin's explicit
  argument indices are 0-based: `%[1]d %[0]s`).
- **Greeter**: every visible string goes through `kit.tr` (also greetd's own
  prompt and error text, so palm-login's "Password:" and "The password was not
  accepted." come out translated). Catalogues `distro/locale/{fr,de,es,ar,
  ja}/greeter.msg`. The date is `trf("%[0]s, %[1]d %[2]s %[3]d", weekday,
  day, month, year)` with names from the catalogue, so each language orders it
  itself (`mardi 13 octobre 2026`, `2026年10月13日（火曜日）`). Arabic mirrors
  the card, the notices and the footer (rows emitted in reverse, text
  `text-right`), arrow icon flipped; the password field is not mirrored.
  `greeter --lang LANG` overrides the environment (also before `--shots`).
- **Greeter clock in local time**: `local_zone()` in `apps/greeter/system.odin`
  loads `TZ` if set, else `/etc/localtime` (TZif) with `core:time/timezone`;
  the offset is recomputed every frame, so DST changes show. It replaced
  `date +%z` read once at start.
- **palm-login** (`distro/login/locale.odin`): before every session start
  (greeter and user) reads `/etc/locale.conf` and exports `LANG`, `LANGUAGE`
  and `LC_*` if set — only those keys, values without spaces/quotes, so the
  file cannot inject `PATH`/`LD_PRELOAD`. Overrides base_env's `LANG=C.UTF-8`;
  the greeter's `start_session` env still wins. `TZ=<zone>` from
  `/etc/timezone` only when `/etc/localtime` is missing (or dangling). Paths
  are fields of `Paths` (`locale_conf`, `timezone`, `localtime`).
- **palm-init** (`distro/init/locale.odin`): the same `/etc/locale.conf` keys
  for every service, read before each start (so a service restarted after the
  installer rewrote the file gets the new language); a service file's own
  `env = LANG=...` still wins.
- **distro/base**: `/etc/locale.conf` `LANG=en_US.UTF-8`; `/etc/palm/keyboard`
  `layout = us`, `variant =`, `options =`; `layout` gains
  `symlink etc/localtime ../usr/share/zoneinfo/UTC` (generate.sh turns it into
  a `symlink =` line of palmframe-base; verified in the rebuilt rootfs).

## For others

- **installer / install_core**: write `/etc/locale.conf` as `LANG=<ll_CC>.UTF-8`
  (one line is enough). palm-login rereads it at every greeter start, so the
  first boot after install is already in the chosen language. For a live
  switch inside the installer use `kit.i18n_set_language`; `i18n_is_rtl()`
  then says whether to mirror. The catalogue header's `name =` / `english =`
  are there for `list_languages`.
- **wm** (bar clock): use local time the same way — `core:time/timezone`
  `region_load_from_file("/etc/localtime", ...)` + `datetime_to_tz`, or copy
  `local_zone`/`zone_offset` from `apps/greeter/system.odin`. Sessions get no
  `TZ` unless `/etc/localtime` is missing.
- **integration** (done 2026-10-13: palm verify treats /etc links and files as
  config; see notes/palm.md): `/etc/localtime` belongs to palmframe-base as a symlink;
  the installer replaces it, so `palm verify` on an installed system will
  report palmframe-base's `/etc/localtime` as changed (and `/etc/locale.conf`,
  `/etc/palm/keyboard` likewise). If palm grows a notion of config files
  (apk's "protected paths"), these three belong there.

## Gaps

- The greeter's layout mirroring is done by hand per row; palmy has no
  `flex-row-reverse` / `dir-rtl`. Mixed-direction strings rely on palmy's
  per-text bidi (the Arabic hint line was reworded to start with Arabic so
  its base direction comes out right to left).
- Japanese renders only where a CJK font exists (host: yes; image: only with
  `fonts-cjk`).
- Weekday/month names are full forms only (no abbreviations, so no "May"
  ambiguity); no msgctxt support.
- Digits are Western in every language, the clock is always 24-hour.
